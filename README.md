# Sora Sushi 空

Лендинг суши-кафе с меню, корзиной, акциями, оформлением доставки и онлайн-оплатой.
Весь сайт — один файл `index.html` (стили и скрипты внутри) плюс папка `assets`.
Серверная часть нужна только для приёма оплаты и лежит в `functions/api/`.

## Что где менять

| Что | Где |
|---|---|
| Меню и цены | `index.html`, массивы `MENU` и `SETS` |
| Акции, скидки, доставка | `index.html`, объект `PROMO` |
| Куда приходят заявки | `index.html`, объект `SEND` |
| Онлайн-оплата | `index.html`, объект `PAY` + переменные окружения (ниже) |
| Цены на сервере | `functions/api/_price.js` — **дублируют** `MENU`/`SETS`/`PROMO` |

> Цены продублированы намеренно: сумму платежа считает сервер, иначе её можно
> подменить в браузере и оплатить заказ на 1 сом. При правке меню обновляйте оба места.

## Акции и их экономика

- минимальный заказ на доставку — 700 сом
- доставка 200 сом, бесплатно от 1500
- 3 позиции и больше — чайник сенчи в подарок
- скидка 5% от 2000, 8% от 3000, 12% от 5000 сом — **только на позиции меню**
- самовывоз — минус 10%, но не больше 150 сом

Проценты подобраны так, чтобы при фудкосте 32%, упаковке ~25 за позицию и курьере 200
маржа держалась около 45–46% на всех порогах, а абсолютная прибыль росла.
На сеты процент не начисляется: они уже продаются со скидкой 20–25%, и наложение
двух скидок съело бы маржу. Потолок 150 на самовывозе всегда ниже стоимости курьера.

## Куда приходят заказы

Заполните **один** из вариантов в объекте `SEND` (приоритет сверху вниз):

```js
const SEND={
  web3formsKey:'',              // ключ с web3forms.com — заказы на почту, без бэкенда
  telegram:{token:'',chat:''},  // токен бота и chat_id
  whatsapp:'',                  // 996700000000
  email:'zakaz@sora-sushi.kg'   // запасной вариант: откроется почтовая программа
};
```

Ключи можно не хранить в этом файле — объявите `window.SORA_SEND` в отдельном
теге скрипта **выше** основного.

## Онлайн-оплата

В `index.html` поставьте `PAY.mode='api'`. Дальше — сервер.

Функции написаны под **Cloudflare Pages** (бесплатно, деплой с этого же репозитория).
На GitHub Pages они работать не будут: там только статика.

### Развернуть

1. dash.cloudflare.com → Workers & Pages → Create → Pages → Connect to Git → `sora-sushi`
2. Framework preset: **None**, build command пустой, output directory: `/`
3. Settings → Environment variables → добавить переменные провайдера (ниже)
4. Свой домен — Custom domains, бесплатно

### Freedom Pay — Кыргызстан

Одна интеграция закрывает практически все способы оплаты в стране:
Visa, Mastercard, **Элкарт**, **О!Деньги**, **Balance.kg**, **MegaPay**,
мобильные приложения **MBank** и **Optima24**.

```
PAY_PROVIDER          = freedompay
FREEDOMPAY_MERCHANT_ID= ваш merchant id
FREEDOMPAY_SECRET     = секретный ключ из личного кабинета
PAY_CURRENCY          = KGS
FREEDOMPAY_TEST       = 1   ← только на время тестов, потом убрать
```

Что сделать в кабинете Freedom Pay: подключить магазин (нужен договор, подключение
и платёжная страница бесплатны, комиссия обсуждается) и указать адрес уведомлений
`https://ваш-домен/api/pay-webhook`, метод POST.

Подпись `pg_sig` проверяется и на приём, и на ответ — без этого кто угодно
может прислать «оплачено».

### ЮKassa — Россия

```
PAY_PROVIDER    = yookassa
YOOKASSA_SHOP_ID= ...
YOOKASSA_SECRET = ...
PAY_CURRENCY    = RUB
```

В кабинете ЮKassa укажите webhook `https://ваш-домен/api/pay-webhook`.
Статус платежа перезапрашивается у API — уведомлению на слово не верим.

### Любой другой провайдер по ссылке

```
PAY_PROVIDER = link
PAY_LINK     = https://pay.example.kg/?amount={sum}&order={order}
```

`{sum}` и `{order}` подставляются автоматически. Годится для провайдеров,
которые выдают параметризованную платёжную ссылку без подписи.

### Уведомления об оплате в Telegram

Необязательно, работает с любым провайдером:

```
TELEGRAM_TOKEN = токен бота
TELEGRAM_CHAT  = chat_id
```

## Что осталось заполнить

Телефон, адрес и ссылки на соцсети в разметке — плейсхолдеры
(`+996 700 000-000`, «г. Город, ул. Примерная, 1», `href="#"`).
Валюта витрины — сом (`CURRENCY` в `index.html`, `CURRENCY_LABEL`
в `functions/api/_price.js`). Цены блюд взяты как есть из прежней версии —
подставьте реальный прайс кафе.
